# Rules

The rules this game implements. One file per topic, written in our own words.

These are a simplified take on Trench Crusade. Where they differ from the official
rulebook, these files win. Do not paste official rules text here: the repository is public.

## How to write a rules file

- State the rule so that a program could follow it: no "agree with your opponent".
- Give numbers and units (inches, dice, markers).
- End with an "Open questions" list for anything undecided. Code is only written for
  rules with no open question attached.
