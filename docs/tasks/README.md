# Task briefs

One file per piece of work, numbered in order. A brief is written in the planning
thread and implemented in its own execution session.

## Starting an execution session

Open a new session in this folder and say:

> Implement `docs/tasks/NNN-name.md`. Read `CLAUDE.md` and `docs/design.md` first.

## What a session reports back

- What was built, and the test output.
- Anything in the brief that turned out wrong or impossible.
- Anything out of scope it noticed but did not do.
